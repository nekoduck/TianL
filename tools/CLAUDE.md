# tools/
> L2 | 父级: /CLAUDE.md

开发工具，不随游戏运行、不进测试。量尺与回放只读世界与样本、不调用模型、不发网络请求——同一份证据交给新旧引擎，前后可比；唯 playtest 经 narrative/llm 真打一局，是本地试玩。

成员清单
replay.py: 量尺——读 tests/fixtures/replay80.json（80 回实录的逐回合样本），以 world/lexicon 的词表体检旧对局的导演节拍与编剧正文，按违例种类统计并列出例子，另量身体两项(无伤扣血 baseless、研习伤身 study_hurt)与打转(逐回合重放节奏账，报出阻尼器会在哪些回合喊停)；python -m tools.replay [--show 种类|all]；每一批重构都拿它对比基线、校准误报与漏报
rerun.py: 回放验收(v5；v6 认得账房这一角色，逐回合报告结算入账与账文分歧，旧日志没有账房即只以词表对账；v7 认得复核这一角色(旧日志没有即当失声、那几句只记分歧)，另报补记与新立的外号)——parse 读一份对局日志(markdown：每回合「#### 角色（trace 第 N 行…）」下是系统提示与上下文，其后是模型的原始输出)，ReplayLLM 按回合吐出真实的导演首稿与返工、编剧正文，史官、推演、书记按出现次序排队，驱动当前引擎重演；逐回合报告去处、场况、眼前与名册、所盯人物的真实下落、未成立之事、返工/体检/原著日志、亲见与传闻、选项，末附账本与原著结算；python -m tools.rerun 日志.md [--turns N] [--watch 段誉,钟灵] [--out 报告.md]；世界会与原局分叉，它量的是新引擎能否接住真模型的写法，不是复刻原局——v5 由它抓到三处病：主角「去」原地即崩、同在一片而被写进拍里的人整拍作废、导演先演了原著那一走就把原著的说法换成清单
playtest.py: 本地试玩(v5；v6 后台视角逐回合摊开结算入账与账文分歧、所盯人物的识名，正文与账本对不对得上一眼可见；v7 另摊开账本替正文补记的与新立的外号)——按固定路线(ROUTES「琅嬛」：剑湖宫搭话→后山→谷底→石门→琅嬛福地→研习→出洞，原著里段誉坠崖得北冥的那条路，主角先走一遍)或自备的一行一举(「1」「2」「3」即选上一回合的第几项)真打一局，写出对局记录：逐回合的举动、正文、选项、身况、亲见与传闻、未成立之事，与后台视角(眼前、名册、此地另有其人、场况、所盯人物的真实下落)，末附客观账本与原著结算；python -m tools.playtest [--route 琅嬛] [--deeds 文件] [--turns N] [--offline] [--watch 段誉,钟灵,木婉清] [--out saves/playtest.md] [--trace 调用.jsonl]；读 GEMINI_API_KEY(环境变量或 .env)，说书人失声的回合记为作罢、接着打下一回合，--offline 只验证流程；同一条路线前后各打一局即可对比段誉何时何地与主角相遇、原著主线断没断、传闻与账本对不对得上
