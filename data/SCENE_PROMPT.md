# 场景清单规范（18_scenes.json）

> 用法：一处原著场景要「言出法随」，就在 `canon/18_scenes.json` 的 `scenes` 里为它布一份清单。
> 世界生成时 genesis 把它编进图里；此后剧情只能调度清单里的东西，不得新造。可把本文连同原著全文交给持有原文的 AI 起草，再人工核对。

## 一、原则

1. **只布原著里有的，或原著暗示其存在的。** 原著明写者 `inferred: false`；原著只暗示其存在、名目或形制由情理推定者 `inferred: true`，`basis` 引原文写明出处。宁缺毋滥：建筑尤其如此——原著没有正面写过的处所，先在原文里找到它的痕迹再立。
2. **时间切片同 EXTRACT_PROMPT：故事开端那一刻。** 谁拿着什么、什么摆在哪里，以开端为准；此后的变化归原著事件与剧情。
3. **够用即止。** 一处场景要布到：此地发生的原著情节与玩家顺手会碰的东西都有着落(厅里有剑架、剑架上有剑)，导演不必为此新造任何一件。
4. **id 即名字。** 取原著或情理中的叫法，不得与书中人名、地名、器物名及其别名相撞；同类之物带上处所或主人以示区别(剑架青钢剑、宾客茶碗、钟灵皮囊)——系统认得它们的简称(青钢剑、茶碗、皮囊)。

## 二、格式

```json
{"scenes": [{
  "scene": "剑湖宫",            // 已登记的地点：这一处场景的根
  "src": "第1回",
  "places": [                   // 建筑：新立的子地点
    {"id": "剑湖宫·宫门", "parent": "剑湖宫", "desc": "≤60字", "lore": ["≤50字"], "state": null,
     "src": "第1回", "inferred": true, "basis": "原文依据"}
  ],
  "roads": {"remove": [["剑湖宫", "无量山"]],          // 与 15/16 同一补丁口径，接在其后读入
            "add": [["剑湖宫", "剑湖宫·宫门", 0], ["剑湖宫·宫门", "无量山", 0]]},
  "features": [                 // 景物：不可携带的陈设，只可改现状
    {"id": "练武厅剑架", "location": "剑湖宫·练武厅", "desc": "只写它自己，不写上面摆着什么", "src": "…", "inferred": true, "basis": "…"}
  ],
  "items": [                    // 器物：location 与 holder 有且只有一个
    {"id": "宾客茶碗", "grade": "寻常", "location": "剑湖宫·练武厅", "spot": "宾客椅旁的茶几上"},
    {"id": "剑架青钢剑", "grade": "器物", "kind": "兵刃", "location": "剑湖宫·练武厅", "spot": "剑架上",
     "desc": "≤40字，此刻看得见的样子", "props": {"材质": "青钢", "长短": "三尺有余"}},
    {"id": "剑会胜负簿", "grade": "要物", "kind": "文书", "location": "剑湖宫·练武厅", "spot": "…",
     "desc": "…", "props": {"执笔": "…"}, "text": "文书的内容(原文或要旨)", "secret": "导演独知的底细(可省)",
     "hidden": false, "hint": "暗藏时：藏在何处、怎样才找得着"}
  ]
}]}
```

## 三、器物的三等

| grade | 用途 | 必填 | 可填 |
|---|---|---|---|
| 寻常 | 茶碗、瓜子：只要有名字 | id、所在 | spot |
| 器物 | 青钢剑、碎银：几样简单属性 | id、所在、desc | kind、spot、props(名目→一句话)、hidden/hint、effect |
| 要物 | 书信、簿册、地图：详写 | id、所在、desc | 以上皆可，另有 text(内容)、secret(底细) |

- kind 沿用 EXTRACT_PROMPT 的 兵刃|秘籍|药物|毒物|信物|宝物|杂物，文书写 `文书`；缺省为杂物。
- spot 是软的方位：东西被拿走即清，放下便是「地上」；景物的描述因此不必、也不该写上面摆着什么。
- 要物的 text 在它到了主角手里时才交编剧；在此之前只在导演后台。secret 只在导演后台。

## 四、校验(genesis，错一处拒绝开局)

- 新 id 不得与既有节点或索引别名相撞；建筑的 parent 须在场景之内(场景根或它下辖的地点)；
- 景物与器物的所在须在场景之内；持有者须是开端时身在场景里的人；
- grade 只有三等；器物与要物须有 desc；只有要物写 text；props 只能是 {名目: 一句话}；
- 道路补丁删的路须在、加的路须无。

改完跑 `python -m unittest discover -s tests -t .`；`tests/test_scenes.py` 是剑湖宫这一份的验收。
