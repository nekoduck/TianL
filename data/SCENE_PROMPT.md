## 提示词正文

你是一名严谨的文学数据工程师。你手上有金庸《天龙八部》世纪新修版全文，以及这个文字沙盒游戏已从原著抽取好的硬知识(附件：地点、门派、人物、器物、原著事件，统一 id)。
这一次要补的是**场景清单**：原著每一处场景里实实在在有的东西——建筑、陈设、器物、银两、成群的无名之众——以及几样散在全书的账：门派弟子的样子、有名之人身上的零钱、原著器物的详细内容、谁不识字。

游戏的规矩是「言出法随」：说书的 LLM 只能调度清单里有的东西，不能凭空造出一封信、一锭银子、一队人马；凡是有数量的东西都有数(地上二两碎银，拿走一两便剩一两)。所以清单里没有的东西，玩家在那一处就永远找不到——**该有的要布齐，原著没有的不要编**。

### 一、总原则（必须遵守）

1. **只取原著里有的，或原著暗示其存在的。** 原著明写者 `"inferred": false`；原著只暗示其存在、名目或形制由情理推定者 `"inferred": true`，并在 `basis` 里引原文写明依据(≤60字)。宁缺毋滥。
2. **统一 id。** 引用的人物、地点、门派、器物、原著事件一律用附件里已登记的 id。新立的 id(建筑、景物、新器物、人群)取原著或情理中的叫法，**不得与附件里任何 id 或别名相撞**；同类之物带上处所或主人以示区别(剑架青钢剑、宾客茶碗、钟灵皮囊)——游戏认得它们的简称(青钢剑、茶碗、皮囊)。
3. **时间切片：故事开端那一刻**(元祐六年二月，第一回第四场比剑之前)。器物摆在哪里、在谁手里、谁身上有多少钱，都以开端为准；此后的变化归原著事件(08)，不要写进清单。
   后来才登场、或只在某一段出现的成群之众(聚贤庄群雄、万仙大会群豪)，用 `since`/`until` 标出出没的时段(见 4.1 人群)。
4. **原著器物不重复立。** `05_items.json` 里已有的 98 件(北冥神功卷轴、汪剑通信……)不在场景里另立一件；要补它们的等级、内容、份数、状态，写进 `canon_items`(4.4)。
5. **够用即止。** 一处场景要布到：此地发生的原著情节与玩家顺手会碰的东西都有着落(厅里有剑架、剑架上有剑；书房里有笔墨纸砚)，说书人不必为此新造任何一件。
6. **出处。** 每条带 `"src": "第N回"`。
7. **只输出纯 JSON**，不加注释与 markdown 标记，UTF-8；字数上限严格遵守。

### 二、度量衡

**银两(两)。** 一两银子约当一贯钱(千文)；一钱是十分之一两。

| 身份 | 开端时身上的零钱(两) |
|---|---|
| 乞丐、小厮、婢女、庄丁 | 0 ~ 0.1 |
| 寻常门派弟子、帮众、兵丁 | 0.1 ~ 0.5 |
| 武师、镖头、江湖散人、僧道 | 0.3 ~ 3 |
| 掌门、帮主、长老、寺院执事 | 2 ~ 10 |
| 富商、豪绅(多装在钱袋里) | 10 ~ 50 |
| 王公贵胄(多为金叶子、银票) | 10 ~ 100 |

参照：一顿饭几十文、客店一宿百来文、一匹好马二三十两。钱袋写作器物带 `purse`(里头有几两)；银票写作器物带 `purse`(票面几两)；地上的碎银写作器物 `cash: true`、`qty` 为几两。

**人群的功力与人数。** 每人功力 `power` 按 EXTRACT_PROMPT 的锚点估：无量剑弟子=15(已布)；庄丁、家丁、婢女 5~10；寻常帮众 10~20；门派弟子 15~25；精锐(少林武僧、灵鹫宫九部女将、一品堂武士) 25~40；兵丁 15~25。
游戏里一人之力是 1.08^功力，整群之力是 人数 × 1.08^每人功力——**整群之力约当一个功力为「每人功力 + 下表加成」的高手**；对整群夺物、杀伤须胜过整群，突围只须胜过整群的一半(加成再减 9)：

| 人数 | 3 | 5 | 10 | 15 | 20 | 30 | 50 | 100 | 200 |
|---|---|---|---|---|---|---|---|---|---|
| 加成 | +14 | +21 | +30 | +35 | +39 | +44 | +51 | +60 | +69 |

例：十五个功力十五的无量剑弟子 ≈ 一个功力五十的好手；聚贤庄三百群雄若每人功力二十五，≈ 功力九十的高手——乔峰(95)力战群雄、难以久持，与原著相合。估人数与功力时，让原著里的胜负在这套算法下说得通。

**路程**：同 EXTRACT_PROMPT——步行日数，同一处所之内的相邻子区域记 0；genesis 统一换算为骑马。

### 四、字段

#### 4.1 `scenes[]`：一处场景

```json
{
  "scene": "剑湖宫",                       // 已登记的地点(01)：这一处场景的根；下面的一切都落在它与它下辖的子地点之内
  "src": "第1回",
  "places": [                              // 建筑：01 里没有、原著有场景或暗示其存在的子处所
    {"id": "剑湖宫·宫门", "parent": "剑湖宫", "desc": "≤60字，景观", "lore": ["≤50字的硬设定，至多5条"], "state": null,
     "src": "第1回", "inferred": true, "basis": "…"}
  ],
  "roads": {                               // 道路补丁(给新建筑连路、改原路)，与 15/16 同一口径：[地点, 地点, 步行日数]
    "remove": [["剑湖宫", "无量山"]],         // 要删的路须已存在
    "add": [["剑湖宫", "剑湖宫·宫门", 0], ["剑湖宫·宫门", "无量山", 0]],  // 要加的路须不存在
    "change": []                            // 要改日数的路须已存在
  },
  "features": [                            // 景物：不可携带的陈设(梁、座椅、剑架、书案、井、石壁、铁笼)，只可改现状
    {"id": "练武厅剑架", "location": "剑湖宫·练武厅", "desc": "≤40字，只写它自己，不写上面摆着什么", "state": null, "hidden": false,
     "src": "第1回", "inferred": true, "basis": "…"}
  ],
  "items": [ … 见下表 … ],
  "squads": [ … 见下表 … ]
}
```

**器物 `items[]`**——三等：

| grade | 用于 | 必填 | 可填 |
|---|---|---|---|
| 寻常 | 茶碗、瓜子、蒲扇：只要有名字 | id、着落 | spot、qty/unit/split、uses |
| 器物 | 青钢剑、碎银、钱袋、信笺：几样简单属性 | id、着落、desc | 以下皆可(text 除外) |
| 要物 | 书信、簿册、地图、秘籍、榜文：详写 | id、着落、desc | 以下皆可，另有 text、secret |

| 字段 | 说明 |
|---|---|
| `id` | 新立之名(不得与附件里任何 id、别名相撞) |
| 着落 | `location`(地点 id，须在场景之内) **或** `holder`(人物 id，须是开端时身在场景之内的人)，有且只有一个 |
| `kind` | 兵刃 / 秘籍 / 药物 / 毒物 / 信物 / 宝物 / 杂物，书信簿册写 文书；缺省杂物 |
| `spot` | 软方位(剑架上、书案上锁的抽屉里)；被拿走即清，不必写在人手里的东西上 |
| `desc` | ≤40字，此刻看得见的样子(不写原著的过去与未来) |
| `props` | `{"名目": "一句话"}`，值一律是字符串(材质、长短、执笔、墨迹) |
| `text` | 只给要物：文书的内容，原文或要旨，≤200字；摆在桌上的信不等于有人读过——到了主角手里才读得到 |
| `secret` | 导演独知的底细(这本簿子是谁伪造的、这幅图藏着什么)，未经揭示不会说破 |
| `hidden` / `hint` | 暗藏之物写 `hidden: true`，`hint` 写藏在何处、怎样才找得着(≤50字) |
| `effect` | 药物、毒物、宝物的效用(≤40字) |
| `qty` / `unit` | 有数的东西：几粒、几张、几支、几坛(正数)；不写即一件 |
| `split` | 拿得出一部分的(一把瓜子、一叠纸、一壶酒)写 `true`；一柄剑、一本簿子不写 |
| `cash` | 地上的碎银写 `true`，`unit` 即「两」、`qty` 即几两 |
| `purse` | 钱袋、银票里头有几两(人拿着它，钱就算他的) |
| `full` / `pages` | 一部书、一叠图、一封撕开的信：`full` 全本几份；`pages` 所存的是哪几份(从 0 数起，缺省即前 `qty` 份)——几份落到一人手里即拼回完整，残卷只研习得到所存份数对应的那一阶 |
| `torn` | 撕开的残片写 `true`(须同时写 `full`)：只读得到自己那一段，要人拼合才合回一件 |
| `uses` | 用途，一列字：`书写`(笔墨)、`纸`(信笺、纸张)——剧中人要写信，手边须有这两样；书房、客店、寺院、王府里该有的就布上 |
| `doc` | 文书的状态：`{"state": "写成"}`、`{"state": "封缄"}`(火漆封口，拆开才读得到)、`{"state": "拆封"}` |

**人群 `squads[]`**——原著里成群出现、没有名字的人(弟子、帮众、僧众、兵丁、庄丁、婢女、家将、群豪)。有名有姓的人已在 04 里，不要算进人数：「身后站着二十余名弟子」而其中五人有名，人群写十五。

```json
{"id": "东宗弟子众", "faction": "无量剑东宗", "location": "剑湖宫·练武厅", "count": 15, "power": 15, "handle": "东宗弟子",
 "desc": "≤30字，看得见的样子",
 "kit": {"money": 0.3, "items": [{"name": "长剑", "kind": "兵刃", "desc": "≤20字", "steal": true},
                                  {"name": "衣衫", "kind": "杂物", "desc": "≤20字", "steal": false}]},
 "leader": "左子穆", "since": "08 事件id", "until": "08 事件id",
 "src": "第1回", "inferred": true, "basis": "…"}
```

| 字段 | 说明 |
|---|---|
| `id` | 新立之名，建议以「众」收尾 |
| `faction` | 已登记的门派(03) |
| `location` | 开端时(或 `since` 那一桩原著到期时)所在，须在场景之内 |
| `count` | 人数，3 ~ 200(不足三人的不立成群：剧情里散了的群也是不足三人即散) |
| `power` | 每人功力，0 ~ 100 的整数(见第二节) |
| `handle` | 旁人对他们的叫法(东宗弟子、神农帮帮众、少林僧众) |
| `kit` | 每人身上一样的东西：`money` 每人几两零钱；`items` 各有不同的名字，`steal: false` 的穿在身上偷不下。省略即用这一门的门下模板(4.2) |
| `leader` | 带队的有名之人(可省)：原著事件把他挪到别处，同在一处的这一群随他走 |
| `since` / `until` | 出没的时段(可省)：`since` 那一桩原著到期之后才在江湖上，`until` 那一桩结算之后便散去 |

#### 4.2 `kits`：门下模板

凡有成群门人的门派各写一份——剧情临时要一队这门的人马、附近又没有布好的人群时，系统按它补人(人头、零钱、兵刃、衣衫)，绝不凭空立有名有姓的人。

```json
"kits": {"神农帮": {"handle": "神农帮帮众", "power": 18, "money": 0.2, "desc": "≤30字",
                    "items": [{"name": "药锄", "kind": "兵刃", "desc": "…", "steal": true}, {"name": "短褂", "kind": "杂物", "steal": false}]}}
```

至少覆盖(id 以 03 为准)：丐帮、少林派、天龙寺僧团、神农帮、星宿派、灵鹫宫部属(及昊天部至钧天部九部)、姑苏慕容(家将)、大理国(禁卫)、西夏国、西夏一品堂、大辽(兵丁)、女真族、三十六洞七十二岛、青城派、秦家寨势力、四大恶人(门下)，
以及原著里成群出现的其余门派与势力；门派里没有成群门人的不写，03 里没有登记的门派不写(先在问题清单里提出)。

#### 4.3 `money`：有名之人开端时身上的零钱

04 里在原著中露过面的人物，每人一条(按第二节的身份表估；原著写明的照原著)。钱袋另写成器物(带 `purse`、`holder` 为他)，不要重复算进零钱。

#### 4.4 `canon_items`：原著器物补注

05 的 98 件逐件补上：`grade`(三等之一)，要物写 `text`(原文或要旨)与 `secret`；一部有几册几卷几幅的写 `full`(六脉神剑经六幅图谱、易筋经)，缺了几份的写 `pages`；封着口的信写 `doc`；撕开的写 `torn`；有数的写 `qty`/`unit`。
只可补这些字段：`grade props text secret qty unit cash purse split full pages torn uses doc spot`——**着落、持有者、是否暗藏、类别与描述归 05 与原著事件，不在此改。**

#### 4.5 `illiterate`：不识字的人

原著写明或可确信不识字的人(写不成信、读不了文书)，每人一条带 `basis`。没有依据的不写——缺省人人识字。

### 六、工作流程（请严格分步）

1. **第一步**：通读附件，列出本次要布的场景与每处的原著回目；先查 01 里已有哪些子地点，缺的才立建筑。
2. **第二步**：按上表顺序分批输出 `scenes[]`，每批 3~5 处场景；每处依次写 places → roads → features → items → squads。
3. **第三步**：输出 `kits`。
4. **第四步**：输出 `money`(按 04 的顺序)。
5. **第五步**：输出 `canon_items`(按 05 的顺序，98 件逐件)。
6. **第六步**：输出 `illiterate` 与 `notes`。
7. **第七步：自检**，按第七节逐条确认，附一份问题清单(原著矛盾、拿不准的推定、未布的场景)。

### 七、自检清单（genesis 逐条校验，错一处拒绝开局）

- 新立的 id 不与 00 里任何 id、别名相撞；`scene` 是已登记的地点，建筑的 `parent` 在场景之内；
- 道路补丁：`remove`/`change` 的路已存在、`add` 的路不存在；
- 景物与器物的 `location` 在场景之内；器物有且只有一处着落；`holder` 是开端时身在场景之内的人；
- `grade` 只有三等；器物与要物有 `desc`；只有要物写 `text`；`props` 是 {名目: 一句话}；
- `qty` 是正数；`cash` 的单位是两；`purse` 是数；`full` 是不小于 1 的整数、`pages` 落在 0 ~ full-1 且不重复；写了 `torn` 必写 `full`；`uses` 是一列字；`doc.state` 是 写成/封缄/拆封；
- 人群：`faction` 已登记、`location` 在场景之内、`count` 在 3 ~ 200、`power` 是 0 ~ 100 的整数、每人零钱是数、身上之物各有不同的名字；`leader` 是已登记的人物、`since`/`until` 是 08 的事件 id；
- `kits` 的门派已登记、形状同人群的 kit；`money` 的人物已登记、银两是数；`canon_items` 只补 05 里的器物、只用 4.4 列出的字段；`illiterate` 的人物已登记；
- 时间切片：清单里没有开端之后才发生的变化(谁后来得了什么、谁后来死在哪里)。
