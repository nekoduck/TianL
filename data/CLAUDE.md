# data/
> L2 | 父级: /CLAUDE.md

原著硬知识库。世界的地理、通行条件、人物、门派、器物、武学、关系与原著时间线由此供给基础设施，经 tianlong/world/genesis.py 编译入世。
数据由外部 AI 依 EXTRACT_PROMPT.md 与 ACCESS_PROMPT.md 从《天龙八部》世纪新修版全文抽取(世界底座 19~27 与其余场景的近景依 WORLD_PROMPT.md，草案待审阅)；genesis 校验全部 id 引用与道路补丁，错一处即拒绝开局。

成员清单
EXTRACT_PROMPT.md: 抽取规范，定义 meta/00_index~08_canon 的格式、度量衡（功力锚点/路程/历法）、开端时间切片、隐情标记与分步自检流程
WORLD_PROMPT.md: 世界底座抽取提示词(v11 草案，待审阅；取代 v10 的场景清单提示词 SCENE_PROMPT.md)——可整段交给持有原著全文的 AI：卷首审阅附注(要抽的十部分、定稿后要新做的机制、待拍板的取舍、对 v10 聚贤庄算例的更正)；正文定总原则(原著为纲、史实情理为目，开端切片与 since/until，每个实体标层级，描述只写不变的，功能性人物不起姓名，隐情不进明处)、近大远小(天下/一方/眼前三层，远景近景与三种视图)、度量衡(银钱、物价锚点、身上零钱、功力与整群加成表、路程与城中里数、时辰、人流、医术药力、城镇规模)、取名，与十个文件的格式——19_places 处所卡/新处所/道路补丁(日数 0 另写里数)/关口(钥匙、时辰、关钱、把守)，20_venues 场所模板(房间、陈设、器物、伙计、货品、服务、柜银、招工)与实例，21_goods 银钱/货品目录与效用/各地物价/原著器物补注，22_people 有名之人补注(v11 场外编剧要的：剧情推力 drive、终极所求 goal、心愿 wishes 与了结条件 done_when、手段 means、底线 limits、原著走向 arc)，23_factions 门派补注(v11 另有所图 goal)/新势力/门下模板/人群，24_laws 国法与江湖规矩(v11 另有天龙世界的准则 precepts，审稿人用)，25_lore 消息(谁知道、真假、怎么打听到)，26_nature 物产/险地/气候/路况/节令/作息，18_scenes 40 个场景根的近景(v10 格式加层级与估值)，27_lines 原著剧情线与事件注(v11 新增：线的因果、动机、原著结局，每桩事的作用、情理前提、前提破了按原著的逻辑大约会怎样)；卷首审阅附注另记 v11 修订二(场外编剧要的数据)；工作流程(先交抽取计划)、自检清单与原著大战对照
ACCESS_PROMPT.md: 通行条件补充规范，定义 14_access.json(有向通路的悬崖/机关/秘道/水路等条件、可硬判的 requires、隐秘通路)与 15_roads_patch.json(修正 0 日中枢造成的伪捷径)的格式
canon/meta.json: 版本(世纪新修版)、开端(元祐六年二月，第一回第四场比剑前)、源文校验和、对规范的扩展约定(器物 state/holder、门派 state.leader、reveal_scope 等)
canon/00_index.json: 全书统一 id 与别名(含通行补丁新增的 19 处地点)，另含 events 组供隐情揭示引用
canon/01_locations.json ~ 08_canon.json: 202 地点、191 原路(按步行估算，genesis 换算为骑马)、55 门派、242 人物、98 器物、119 武学、191 关系、235 原著事件——genesis 的输入；
  v5 修订：父节点的设定只写它自己(琅嬛福地的现状不再写「卷轴藏在蒲团内」，玉像刻字归玉像石室，铜镜后室的描述不再说破暗门)，
  二十件器物的描述改为此刻看得见的样子(不再写「传给虚竹」「乔峰折断后用以自尽」「段誉入洞后用来照明」之类原著的过去与未来)
canon/14_access.json: 179 条有向通行条件 {from,to,kind,blocked,hidden,how,requires,risk}——blocked 与 requires(8 条，皆为某处 state)由系统硬判，hidden(21 条)须经剧情发现，how/risk 交导演兑现；阶段性条件(垂链、断桥、围庄)无时间字段，由 how 文字描述
canon/15_roads_patch.json: 原路补丁 remove 17 / add 45 / change 4（外部抽取），genesis 读入时先删再加再改、各只一次，修去 0 日中枢的伪捷径；notes 记每处修正的原著依据，new_locations 已并入 01；不依 01 的 parent 自动连路
canon/16_roads_fill.json: 走廊补丁，同 15 的格式、在其后读入，据既有数据补全而非另行抽取——汉中—长安(第47回段正淳自中原南行经梓潼)、陆凉州—洞庭湖(第9回少林使者南来至陆凉州、第10—11回鸠摩智一月内押段誉自大理抵姑苏)、吐蕃—大理城(两国比邻，鸠摩智自大轮寺赴天龙寺)；大理到中原、江南不再绕道西夏天山，合计 222 条道路连成一片
canon/17_situation.json: 原著事件的情境前提补充 {requires: {事件: [[src, "~关系"/"!关系", dst]]}}——抽取数据只记属性前提，「钟灵仍被司空玄扣为人质」这类情境补在这里，genesis 并入 requires 并校验；救出被擒者的原著事件由系统自动要求拘押仍在，无须重复登记
canon/18_scenes.json: 场景清单(v8，手工据原著布置，非外部抽取；其余场景由外部依 WORLD_PROMPT.md 第十四节抽取，v10 的顶层段落 kits/money/canon_items/illiterate 在 v11 草案里改归 23/22/21/22，genesis 仍认 v10 写法)——先只布剑湖宫一处：建筑 宫门、内堂(原著暗示其存在、名目推定)，道路补丁(出入剑湖宫改经宫门)，景物 练武厅屋梁/掌门座/宾客椅/练武厅剑架/内堂书案，器物 剑架青钢剑、宾客茶碗(寻常)、碎银(v9 二两)、剑会胜负簿(要物)、玉壁剑影图(要物，暗藏；v9 一叠十二张)、内堂笔墨(v9 用途书写)、内堂信笺(v9 二十张，用途纸)与人身上的段誉折扇、钟灵皮囊、钟灵瓜子(寻常，v9 二十粒)、马五德钱袋(v9 二十两)；v9 人群 东宗弟子众、西宗弟子众(各十五人，每人零钱三钱、长剑、衣衫)；每条带 src/inferred/basis；genesis 编入并校验，错一处拒绝开局
