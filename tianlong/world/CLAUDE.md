# world/
> L2 | 父级: /tianlong/CLAUDE.md

基础设施层。掌管世界的唯一真相——地理(含有向关口)、人物、器物、武学由 genesis 从 data/canon 原著硬知识编译而来，LLM 不新造；它是唯一的事实源与裁判：LLM 提议，世界裁决。
替导演记住一切、算好距离功力与时日、裁定通行、预判较量结局、排定原著日程；导演的提议经 adjudicate 逐拍裁决(授意→落账→词表体检)，单条指令经 effects 一个入口落账，选项经 menu 验收；凡有数量的后果由规则算。本目录不 import 任何 LLM 代码，也不 import story/。
v4 状态层：事件先于状态——LLM 宣告发生了什么(ops、拍上的 mood)，系统推导这意味着什么：主角与 NPC 共用 actor 的身体与心境、bond 的恩怨账折叠出立场、growth 的研习账投影出进境；profile 是唯一的投影，界面、编剧、导演只取不同切面。

成员清单
genesis.py: 创世导入器，读 data/canon 编译世界(17 情境前提并入原著 requires 并校验)：裁剪抽取元数据、按章成簇排定原著日程(一章之事落在同日、章内换地多走一日、章与章在月内铺开、日序随 order 单调)、开端未明者休眠(dormant)、道路补丁(15 修伪捷径、16 补走廊)依次先删再加再改且须与原路严丝合缝(删改之路须在、所加之路须无，不依 parent 自动连路)、路程按骑马换算(PACE=0.6)、有向通行条件(14)编译为关口(须落在道路上、requires 引用须已登记)、编译别名表(索引别名与去「·」写法→id，id 优先)、保留隐情的揭示事件 revealed_by 并校验、校验全部 id 引用，错一处即拒绝开局；编译结果缓存、每次深拷贝
world.py: World 聚合根(读档时旧档里「某人→主角」的态度边经 bond.migrate 折成恩怨账)(另持本回合瞬时账 turn：调遣来源、赶来之人、回合开始时身边之人、连带说明，不入存档)，create 创世(genesis + ORIGINS 出身，关口以去向为键挂上道路边；名号与书中人名、地名、别名重名即拒)、from_dump 读档即 remap——以当前创世数据重绘地点定义(保留现状 state)、道路关口、关系的静态标注(secret/revealed_by)与别名，新地点入常识，旧档自动用上新地图且重绘幂等；witness 让导演后果当场入认知(随即离开也记得所见，隐匿者不因此现形)；record 可明说亲历(主角做完便走的事)、apply→record(标记亲历/公开，原著事件可盖排定之日的日戳)→advance→sync 状态流水线、观察校正认知、持有别名表、整世界 JSON 存读档(先写临时文件再原子替换，extra 段供上层附带如 Web 回合记录)
graph.py: 内存图数据库，holds 是原著情境前提与未了之事谓词共用的判定口径(属性相符，或 ~关系 有、!关系 无)；节点属性 + 有向关系边(可带 secret/note/revealed_by) + 无向道路边(days 权重，可带 gates{去向: 关口})；地点 state.accessible/exists 为 false 则道路断绝；ways/roads/distances/path 可由调用方传 through 逐步过滤——不给即纯地理(传闻、LOD)，给了即某人眼中可走的路；matches 是原著前提与通行前提共用的属性判定口径(列表含之、字典逐项且开关缺省为真)
clock.py: 全局时钟，以分钟计数(一刻十五分、一时辰八刻)、原点元祐元年正月初一，advance 返回跨日/跨月数；PACES 时长措辞表(瞬息/片刻/一顿饭/半日/一夜/一日)，minutes() 把措辞换算成分钟、「一夜」算到次日辰时——时间是世界的，不是 LLM 的；渲染并解析(day_of)元祐→绍圣→元符年号历法
blackboard.py: 玩家 JSON 黑板(坐标/气血/功力/姿态/出身与所求/物品/武学/境况 conditions(内伤分级词由 body 升降)/所识之人 acquaintances/节奏账 pacing/来路 came_from/途中 en_route(去向与余程)/未了之事 threads 及其元数据 quests/研习进度 study/伏笔 hooks/回合数 turn/两层叙事记忆；v4 另有正文偏差 drift 与故事账 scene/clocks/arc/spines/setups(由 story/ 维护)；系统维护的这些导演都写不动)，经 effects 的 id="player" 通道写入，hp 无论 set 或 add 都夹在 [1, max_hp]；ORIGINS 三种出身给主角站在剑湖宫的理由；remember 近事满 JOURNAL_CAP 行即挤出最早 FOLD 行交上层折叠进 synopsis
ledger.py: 双账本 + 消息队列——Truth 只追加事件；Knowledge 是公开属性的信念投影(开局排除 secret_fields；开局常识只含地理、门派与名号显赫之人 FAME，无名之辈与器物要亲见或听闻)并记录已揭隐情(限定知情者唯亲历可知)，每个节点记着最新消息的日子(asof)，迟到的旧闻不盖新见；Messenger 以 速度×分量 的波前半径投递传闻(含场外剧情)，亲历之事即时送达，限定知情者之事(public=false)江湖无从传开、主角不在场便永不得闻
adjudicate.py: 裁决器，judge 逐拍裁决导演的提议(每拍落账之后 bond.derive 从已成立的指令推出恩怨事件、actor.feel 把拍上的 mood 挂在此人脸上；拍里写主角「练成、身如游龙」而本回合并无一阶进境即 mastery 违例(交返工，不作废)；imply 追认一回研习——玩家所指的秘籍或武学够得着、主角的拍里写着习练而导演漏写 study，系统补上这条指令；一拍一事务：拍里改变物理状态的指令落不了即整拍返工、仍不成立即作废；无据的指令丢掉——无伤扣血、被荡开的一击、研习之拍扣主角气血，无人出手一拍至多伤五点；场景物件就是此地暗藏的原著器物则认回、揭开暗藏；同伴诸拍落定后才沿主角走过的路随行；擒者与人质须同处；perspective.audit 查称谓)——主角的拍先授意(取走他人或此地之物、毁物、杀人、吸功须在玩家所指之内，越权的拍不演、降为下回合的候选选项)，再经 effects 落账，诸拍之后落此地原著(then 钩子)，最后以 lexicon 体检拍文：写了变化却无指令、让不在身边的人言行、说破未揭隐情、台词说出尚未发生的原著(foretold：将被擒、将死)、无来源的打断、不成立的场景实体为硬违例；拍可带 mood(情绪，只给编剧、不入账)；physical 判改变物理状态的指令(节奏账据此判局面动没动)；词表只追认获救(解押)，随行、离去、叫错名字只返工不作废；doomed 给出返工后仍不成立须整拍作废的拍及缘由(单条指令驳回不作废整拍)，brief 把硬违例连同「那件东西究竟在谁手里、那人究竟在哪」译成返工清单；names/targets 是实体名表与举动所指；同一提议在同一世界上裁决两次结果相同，引擎据此先在副本上试演
lexicon.py: 变化词表与一致性体检(纯函数；「二人」只回指上一句的人)——得失、交出、去留、随行、生死(及物死者在后、不及物死者在前)、吸功、擒放(被擒者紧随其后或「被」字句在前)、现身言行、后台术语、未揭隐情的口语变体、进境(MASTERY 成就性措辞，mastery() 只认主角的、不在否定假设里的；PRACTICE 习练措辞供追认研习)；只认动词与实体同在一句的强证据，否定、假设、回忆、远处一律不算；回放工具与裁决器共用
situation.py: 情境层——原著数据里没有、剧情却要依赖的状态：纠缠之人 entangled(同行者、未了之事所系者，lod 与 effects 共用)、近旁(同一处所、零日、无拦人之关)与身边之人、随行(主角走则跟，过不去的关留下，随行即解押)、受制(扣为人质/囚禁之类的关系边)、命悬一线 imperiled(气血不足 PERIL，兜底选项、幕间省略、后台共用一个口径)、溃退(离场且数日内不得再来)、场景实体(群体须有附近据点或人手且不属原著近事里未到场的势力，物件不得冒用原著器物之名，离远即回收)、未了之事(至多四条、谓词 done_when 满足或所系之人死尽即了结、十二回合未推进提示导演)；每一种都有写入者、读者与自动变化
body.py: 身体规则(主角与 NPC 同构：内伤升降、伤势措辞、养伤都带 who，缺省主角；光阴流过，天下有气血账的负伤之人一同将养)——命运骰 fate(较量与研习预裁共用，试演与定稿一致)；研习预裁 forecast(骰值+会这门的人指点+30、懂易理者解卦位+15 且时长翻倍、每级内伤与气血不足一半扣分 → 顺利×1.5/小有所得/受阻×0.5，岔气只在骰值≤8 且武学有凶险或带伤强练时出现)，RISK 让北冥神功与凌波微步初学无凶险；内伤是境况里的分级词(内息紊乱→经脉受损→经脉重创)，injure/relieve 一回合各至多一级，recover 歇满半日回气血、降一级内伤；wound 以气血(0.8/0.3/0.12)与内伤共同定伤势措辞——重伤只给气血三成以下或经脉受损以上
growth.py: 数值规则——研习先过 body 的预裁再计时长(岔气添一级内伤)；研习分三阶(初窥/小成/大成，累计时长与间隔日数门槛，分阶兑现 grants.power 的四成/三成/三成，同一部秘籍只兑现一次；向身边人求教两个时辰入门、不涨功力)，SITTING 研习一回至少一顿饭(引擎据研习指令给光阴兜底，不随措辞)；北冥吸功按阶取对方功力三/五/七成、吸者只留一半、被吸者负伤；progress 给后台的研习进度一句话；mastery 把研习账投影成每门武学的进境(已会者带阶名、习练中者写已习多久——界面、编剧、导演同看这一份)，兑现阶段时记 turn["advanced"] 供裁决器核对进境措辞；studiable 给够得着的研习对象(手边与此地的秘籍、身边有人会的武学)；被吸者经 actor.declare 负伤
menu.py: 选项出口检查——编剧拟的三项逐项验收：对象够得着(地点走得到、人在身边或同行，不在身边的须是去找他打听他、物在身边或知其下落)、不说破未揭隐情与后台术语、同一对象只留一项；上回合越权未演之举与刚对主角开口之人优先补进(一再重复同一诉求者不再硬塞「回应」)，不足以兜底项补齐——兜底看局面：导演旧写法的选项、途中先给续行、推进未了之事、攀谈、近处一条不是来路的出路(按方向措辞，不报节点全名)、歇息；身处险境(situation.imperiled 或受制于人)不给走开与歇息；编剧标了尺度而三项里没有「此后」之事，以 story/choices 给的 later 兜底项换下最后一项(槽位覆盖，险境里不要求)；返回 (文字, 对象)，对象即下一回合的授意范围
effects.py: 剧情落账器，10 指令 DSL(set/add/push/pull/link/unlink/reveal + arrive 有人赶来/study 研习/drain 吸功)，无新造指令；数值归规则(导演不得直接增减功力、凭空授武学)；在场即近旁；结关系两端须在身边或回合开始时在身边，赶来须光阴够其路程(死者遗体亦可抬来)；一回合一人只听一处来源调遣(导演/原著与史官/场外推演)，LLM 写的场外移动首程不过一日加流逝日数；随行入账即解押、主角走则同伴随之；器物近似名分三层先验(现场含暗藏 > 主角认知 > 全局)、三档字面(包含 > 最长公共子串过半 > 现场器物描述里的说法，「X里的Y」认 Y 不认 X)归一，unearth 把场景物件认回现场的原著器物；导演写内伤只按分级升降、有据的疗伤顺带降一级，道路不可 link/unlink；形状守恒(数值仍是数值、清单仍是清单、随身器物与武学只可逐件得失、门派须已登记)，写歪的指令驳回而非崩溃；器物流转统一经 _hand(持有与落地不兼存、交到主角手里即入随身、脱手无人接便落在原处、丢不下身上没有的东西)；reveal 两地即发现暗路(规整到道路边本身)，且只有导演的揭示当场入认知，原著揭开的隐情随事件入账、经 Knowledge.learn 按传闻或亲历送达；主角移动交 access.walk 裁定路线——绝路寸步不移、门前之关止步、本回合光阴(措辞换算的日数，至少一日)走满即在途中歇脚并记下 en_route，到达或改道即清，最后一步记作 came_from，前半程成立、后半程以人话回告，走过的暗路记入认知；resolve 把主角名号、别名、去「·」写法、不识名之人的叫法归一到 id；一批指令里主角的移动最后执行，在场性以回合开始时的所在为准；地理只可改 state、武学定义不可改、器物只可流转(location/holder/hidden/state)且随持有者走；link 只立结构性关系(随行、拘押、师徒、结义……)与暗中的心思，「某人→主角」的一时看法(疑忌、感激……)经 bond.attitude 记进恩怨账、不立边(v4 删去覆盖与五回合阻尼)，主角对某人的看法只留最新一条；add hp、push/pull conditions 对任何活人成立(NPC 的气血归 actor、status 由气血推出，写 set status 则气血随之对齐；内伤每人每回合至多升降一级)，set intent 改写此人眼下之事、set mood 记下此刻情绪，set conditions 一个字串即添上一样；场外推演与史官动不了纠缠者的去留、生死、拘押；宽松规整后校验世界物理与在场性(休眠者不可触)；describe 把指令译成人话回告编剧；导演触碰的节点记为因果污染
access.py: 通行裁判，barrier 判一步为何走不通(认知先于物理：未发现的暗路对主角即"找不到去路"、不泄露去向；blocked 与 requires 拦所有人，唯主角身陷绝境——stranded：除不通之路外别无出路——时不通之路交导演以奇遇兑现，不困死主角)；distances 主角可走的里程；walk 主角远行(可走的最短路，无路则沿地理最短路走到绝路前；第一步的关导演已看见，途中的关一笔带过，目的地门前的关——通往目的地或同在 0 日一簇——止步留给下一回合；budget 为本回合光阴可走的日数，走满即在途中的原著地点歇脚，回告以 ON_ROAD 开头，以别于受阻)；heading 局部方向措辞(同一处所内出/进/去，跨处所往，不报节点全名)；learn 走过的暗路按整条道路记入认知(认得与否不论道路存储朝向，数据翻转朝向也不会忘)；exits 主角出路(注关口之类，带 way 方向措辞，back 标出来路)、steps 场外人物可去的相邻地(暗路不拦)、passes 此地出发的关口与过法风险、secret_ways 近处未发现的暗路(供导演)
lod.py: 叙事 LOD 调度(纠缠者的原著前提已破即作罢、不唤史官；原著前提经 graph.holds 判定，含 ~关系 情境前提；救人之事须那人仍受制；与主角故事纠缠之人——同行者、未了之事所系者——的场外原著交史官或作罢，entangled 给出这些人；settle 可明说亲历)，按道路距离分 0/1/2 层(此地/一日之内含 0 日簇/远方)；LOD1 选出近处有图谋的人物并落账其场外剧情(只收推演区域之内的战报)；场外之事经 _told 入账——后果全数成立才照录其说法，有不成立的只记成立的要事(生死、去留、易手、恩怨)，一事无成则不入账；原著隐含前提——死者不再登场、主角手中之物不会凭空飞走、正与主角同在一处的人(不论是否相关者)分身不得；原著到期即结算、永远按 order：split_due 把到期原著分为场外待结算与此地上演的一桩(一回合只交出一桩给导演作主干)，upcoming 给出近处数日将至的原著供伏笔；verdict 裁定：干净照原著、被扰动的大事与近处破局交史官、远方小事破局作罢；场外之事的隐含前提——正与主角同在一处的相关者分身不得；settle 盖原著排定之日的日戳，此地亲见者盖今日
