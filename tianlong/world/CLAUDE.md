# world/
> L2 | 父级: /tianlong/CLAUDE.md

基础设施层。掌管世界的唯一真相——地理(含有向关口)、人物、器物、武学由 genesis 从 data/canon 原著硬知识编译而来，LLM 不新造；它服务于剧情：替导演记住一切、算好距离功力与时日、裁定通行、预判较量结局、排定原著日程、把剧情后果落账并传播。只经 effects 一个入口改变，本目录不 import 任何 LLM 代码。

成员清单
genesis.py: 创世导入器，读 data/canon 编译世界：裁剪抽取元数据、按章成簇排定原著日程(一章之事落在同日、章内换地多走一日、章与章在月内铺开、日序随 order 单调)、开端未明者休眠(dormant)、道路补丁(15)先删再加再改且须与原路严丝合缝(删改之路须在、所加之路须无，不依 parent 自动连路)、路程按骑马换算(PACE=0.6)、有向通行条件(14)编译为关口(须落在道路上、requires 引用须已登记)、编译别名表(索引别名与去「·」写法→id，id 优先)、保留隐情的揭示事件 revealed_by 并校验、校验全部 id 引用，错一处即拒绝开局；编译结果缓存、每次深拷贝
world.py: World 聚合根，create 创世(genesis + ORIGINS 出身，关口以去向为键挂上道路边)、apply→record(标记亲历/公开，原著事件可盖排定之日的日戳)→advance→sync 状态流水线、观察校正认知、持有别名表、整世界 JSON 存读档(先写临时文件再原子替换，extra 段供上层附带如 Web 回合记录)
graph.py: 内存图数据库，节点属性 + 有向关系边(可带 secret/note/revealed_by) + 无向道路边(days 权重，可带 gates{去向: 关口})；地点 state.accessible/exists 为 false 则道路断绝；ways/roads/distances/path 可由调用方传 through 逐步过滤——不给即纯地理(传闻、LOD)，给了即某人眼中可走的路；matches 是原著前提与通行前提共用的属性判定口径(列表含之、字典逐项且开关缺省为真)
clock.py: 全局时钟，以分钟计数(一刻十五分、一时辰八刻)、原点元祐元年正月初一，advance 返回跨日/跨月数；PACES 时长措辞表(瞬息/片刻/一顿饭/半日/一夜/一日)，minutes() 把措辞换算成分钟、「一夜」算到次日辰时——时间是世界的，不是 LLM 的；渲染并解析(day_of)元祐→绍圣→元符年号历法
blackboard.py: 玩家 JSON 黑板(坐标/气血/功力/姿态/出身与所求/物品/武学/境况 conditions/未了之事 threads/两层叙事记忆)，经 effects 的 id="player" 通道写入，hp 下限 1；ORIGINS 三种出身给主角站在剑湖宫的理由；remember 近事满 JOURNAL_CAP 行即挤出最早 FOLD 行交上层折叠进 synopsis
ledger.py: 双账本 + 消息队列——Truth 只追加事件；Knowledge 是公开属性的信念投影(开局排除 secret_fields)并记录已揭隐情(限定知情者唯亲历可知)；Messenger 以 速度×分量 的波前半径投递传闻(含场外剧情)，亲历之事即时送达
effects.py: 剧情落账器，7 指令 DSL(set/add/push/pull/link/unlink/reveal)，无新造指令，道路不可 link/unlink；reveal 两地即发现暗路(规整到道路边本身)；主角移动交 access.walk 裁定路线——绝路寸步不移、门前之关止步，前半程成立、后半程以人话回告，走过的暗路记入认知；resolve 把主角名号、别名、去「·」写法归一到 id；一批指令里主角的移动最后执行，在场性以回合开始时的所在为准；地理只可改 state、武学定义不可改、器物只可流转(location/holder/hidden/state)且随持有者走；link 可带 note 印象，某人对主角的关系写新即覆盖旧；宽松规整后校验世界物理与在场性(休眠者不可触)；describe 把指令译成人话回告编剧；导演触碰的节点记为因果污染
access.py: 通行裁判，barrier 判一步为何走不通(认知先于物理：未发现的暗路对主角即"找不到去路"、不泄露去向；blocked 与 requires 拦所有人)；distances 主角可走的里程；walk 主角远行(可走的最短路，无路则沿地理最短路走到绝路前；第一步的关导演已看见，途中的关一笔带过，目的地门前的关——通往目的地或同在 0 日一簇——止步留给下一回合)；learn 走过的暗路按整条道路记入认知；exits 主角出路(注关口之类)、steps 场外人物可去的相邻地(暗路不拦)、passes 此地出发的关口与过法风险、secret_ways 近处未发现的暗路(供导演)
lod.py: 叙事 LOD 调度，按道路距离分 0/1/2 层(此地/一日之内含 0 日簇/远方)；LOD1 选出近处有图谋的人物并落账其场外剧情；原著到期即结算、永远按 order：split_due 把到期原著分为场外待结算与此地上演的一桩(一回合只交出一桩给导演作主干)，upcoming 给出近处数日将至的原著供伏笔；verdict 裁定：干净照原著、被扰动的大事与近处破局交史官、远方小事破局作罢；场外之事的隐含前提——正与主角同在一处的相关者分身不得；settle 盖原著排定之日的日戳
rag.py: 场景触发式 GraphRAG，scene 判定可见之物；build 产出玩家视锥(在场真相/场外认知/已知关系含印象/传闻/出身所求/境况/未了之事/前情梗概/近事/出路)；backstage 产出导演后台(此地上演的原著及其前提/原著近事/较量预裁 rule(档位差×命运骰→结局与失血)/隐匿/暗藏/到时候的隐情(揭示事件已发生或一月内到期)/图谋/功力对比/在场武学/此地关口/近处暗路/主角走得到的近处去向/命运骰/节奏/濒危)；condition 产出身况标签(含境况)；heard 给出已传到某处的江湖近闻(场外推演与史官据此反应，主角所为由此传开)；dossier 产出场外档案
