# world/
> L2 | 父级: /tianlong/CLAUDE.md

基础设施层。掌管世界的唯一真相——地理(含有向关口)、人物、器物、武学由 genesis 从 data/canon 原著硬知识编译而来，LLM 不新造；它是唯一的事实源与裁判：LLM 提议，世界裁决。
替导演记住一切、算好距离功力与时日、裁定通行、预判较量结局、排定原著日程；导演的提议经 adjudicate 逐拍裁决(授意→落账→词表体检)，单条指令经 effects 一个入口落账，选项经 menu 验收；凡有数量的后果由规则算。本目录不 import 任何 LLM 代码，也不 import story/。
v4 状态层：事件先于状态——LLM 宣告发生了什么(ops、拍上的 mood)，系统推导这意味着什么：主角与 NPC 共用 actor 的身体与心境、bond 的恩怨账折叠出立场、growth 的研习账投影出进境；profile 是唯一的投影，界面、编剧、导演只取不同切面。
v6 账文同构：一回合曾有两份「发生了什么」——导演的指令进账本、编剧的正文给玩家，各写各的，账与文必然分叉；如今玩家读到的正文是本回合的定本，settle 把定本里确立而账上没有的变化交世界复核入账(规则之事与落不了的只记分歧)，账本是正文经裁决的投影；识名成了一等指令(reveal 的 id 形)，认知与物理同一条写入通道。
v7 把账文同构补成四条轴：方向——两相对账(文→账由账房入账；账→文由回合首末两份「主角看得见的账」求差，账上变了而正文没写到的由账本补记一段)；身份——叫法即主键(主角叫不出名字的人，撞了叫法即在落笔之前各分一个稳定外号，「容师叔」「钟姑娘」也落得回原人)；校验——双录复核(账房与词表是两个独立的记账员，词表看出而账上没有的句子交账房复核，之后仍对不上的才是分歧)；时间——正文有时间轴(主角这一回合待过的每一处、那里的听众与遗体；正文逐段逐句对齐，动身之前说的话原处的人听见)。名字是谁的(看得见)与谁听见(在耳边)是两个角色。
v8 场景清单：一处场景的建筑、景物、器物在创世时由 genesis 从 data/canon/18_scenes.json 布齐(器物分三等：寻常只有名字，器物带属性，要物详写、文书另有内容与底细)，剧情只调度、不新造——spawn 不再立物件，拍文与正文里凭空拿出的东西即违例或分歧；scenery 把「此刻场景里有什么」翻成 LLM 读得懂的清单，器物的简称让玩家原话认得出所指。
v9 事码与物量：LLM 说的类代码升到语义层——一条事码 {"做":动作,…} 是一件事(拿取、交给、偷取、书写、脱身……)，acts 把平常之事化为十条指令、规则之事照数与预裁执行；stock 管数(银两是数不是器物、拿一部分剩其余、几分之一份)，crowd 管无名之众(十五人一体、指数武力、夺杀须过整群、突围须过一半、偷取看身法、不足三人即散)，scribe 是唯一的造物通道(一台文书有限状态机)。
v10 人群随剧情驱动底层：一群人可远行、赶来、随行、随首领(原著挪走带队之人)、按出没时段在场，打晕的两个时辰醒转；spawn 的一队人马是既有人群的重组(分出几人，身上之物按人头带走，离远并回)或按门下模板补来的纯 NPC，有名之人不立；谁的银两都对账。
v11 场外编剧：主角不在的地方，江湖照样在走——日程里有原著，也有场外编剧写的衍生事件(与原著同一格式)；到期之事前提未变就照日程演(演绎家，不调模型，被主角扰动过也照演)，前提破了：只差路程的延后，附近的与分量重的原著交创作家改写，其余作罢；作罢、被主角拦下、志向被眼前的剧情改了、心愿了了或所系之人死了，此人原著线已变(adrift)，往后的路照志向与剧情推力(drive)交创作家续写。plot 是创作家的规则审(名实、时空、归属、胜负、武学来路、暗藏要知情、地理不动、说法对得上且不剧透)，合不合志向、天龙准则与精彩归审稿人(narrative)；原著线可以断(drops)，断了不必接回。主角近旁只归近处导演：场外叫不来人、碰不到主角身边的人，原著或场外剧情要把人送到主角这里交导演演出来人(lod.coming)；场外的说法过剧透筛子(adjudicate.spoilers)才成传闻。

v11 世界底座：「言出法随」扩到整个天龙世界——founding 把 19~27 编进世界(处所卡、新处所、场所、货品物价、人物门派补注、人群、国法规矩准则、消息、风物、剧情线)，静态的表进 atlas；近大远小：venue 在主角走近时才把场所的近景(房间、陈设、器物、伙计、货架、柜银)布进图里，确定且幂等；伙计按时辰当值，关口认时辰钥匙关钱，零日而有里数的路不是近旁；lore 管知者与消息(开局常识只有天下皆知的，打听来的照原样记)；trade 执行买卖、服用、办事、打探；locale 是世情的读者面。graph 按类型、所在、持有建索引，近旁与名表按戳记缓存。
