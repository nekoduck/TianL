# tianlong/
> L2 | 父级: /CLAUDE.md

游戏本体。三层一线：`world/` 掌管世界（地理、器物、人物、时间、账本、原著日程、情境）并替剧情记忆、算账、裁决、送信、结算——它是唯一的事实源与裁判(v6：玩家读到的正文是每回合的定本，world/settle 把它交世界复核入账，账本是正文经裁决的投影；v7 两相对账、叫法即主键、双录复核、正文有时间轴；v8 场景清单：一处场景的建筑、景物、分级器物在创世时布齐，剧情只调度、不新造；v9 事码与物量：导演与账房说同一种语义层的类代码，银两、数量、几分之一份、十五人一群的无名弟子、剧中人写下的文书都由规则算；v10 人群随剧情远行，一队人马是既有人群的重组或按门下模板补来的纯 NPC，打晕的人两个时辰醒转；v11 场外编剧：主角不在的地方江湖照样在走——原著前置未变照原著演，原著线变了(演不成、被拦下、心愿了了、志向改了)交创作家按志向与剧情推力写新的剧情线，规则审与审稿都过才排进日程，原著线可以断；主角近旁只归近处导演，场外说法过剧透筛子)；`story/` 记住故事走到了哪里（场、时限、原著窗口、主角线、伏笔、选项槽位），每回合给导演一份场记；`narrative/` 提议剧情、成文、拟选项；`engine.py` 是它们唯一的交汇处：LLM 提议，世界裁决，文字只渲染已成立之事。

protocol.py: 前后端契约 tianlong/1.3 的 Python 实现(1.3：选项随 done 放出，head 的 options 为空)——present 把引擎回合译成载荷(选项编号带回合序以识破过期)、relay 把引擎进度译成流式事件、resolve 把行动译回引擎原话(写明的卷与回合须与眼下一致，否则 409 stale_turn)、ProtocolError 携带 HTTP 状态与错误码；契约正文在 web/PROTOCOL.md
server.py: 传输层——标准库 ThreadingHTTPServer 托管 web/ 静态前端与 /api/session(续读/开卷)、/api/action(行动)；POST 只收同源 JSON(跨站 403)、Content-Length 须为非负整数；Accept 含 text/event-stream 时以 SSE 推送(首事件才开流，之前的错误仍为 JSON；读者离席回合照写)；Hub 单机单局、一锁一笔(忙则 409)、每回合自动存档(终端存档格式 + web 段)，Session 可开卷/续卷(续卷记得上回合末段)；开流前后读者离席都不打断回合；不含游戏逻辑
cli.py: 终端表现层，选名号与出身、展示正文/亲见与传闻/身况标签/验收过的 3 个选项，处理自由输入(半角数字即第几个选项，此快捷写法只在终端；说书人失声即提示重试，世界已回到回合开始)与 /save(先汇合后台梗概) /load /me /debug 指令(读档失败只提示、不丢眼前这一局)，读取 .env；--web 时改为启动 server 并续读 --load 存档或上次的自动存档(坏档不覆盖)，--trace 记录大模型调用
