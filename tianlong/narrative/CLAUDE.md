# narrative/
> L2 | 父级: /tianlong/CLAUDE.md

剧情层。LLM 提议，世界裁决：导演读 world/rag 的视锥与后台逐拍提议(每拍挂着自己的后果 ops)，由 world/adjudicate 裁决，账本对不上就返工一次；编剧只凭已成立之事成文，写完再拟三个带对象的选项与一条伏笔，由 world/menu 验收。不新造原著的人、地、物，不必记忆、不必算账、不必裁决、不必报时——那是基础设施的事，它只选措辞、只演出。换模型只动 llm.py，换文风与叙事纲领只动 prompts.py。

成员清单
llm.py: Gemini REST 网关(urllib 直连，text/json/stream 三种调用，stream 走 streamGenerateContent?alt=sse，sse_texts 为可单测的解析器并记下收尾缘由；连不上、超时、断流(IncompleteRead)、回包不是 JSON、被安全策略半途截断一律化为 LLMError 交兜底；thinkingBudget=0 省 token，累计 tokens 与 trace 加锁(场外推演、梗概折叠与编剧并行)，可选 trace 把每次调用记成 JSONL(含 finishReason)供提示词迭代)，from_env 读取 GEMINI_API_KEY/GEMINI_MODEL；v5 strict=True：导演这一笔失败即整回合作废，不以离线说书人代演
prompts.py: 提示词组装器(v4：导演上下文第一节是【场记】(gm["brief"]，有场记时后台不再列【节奏】)；人物行带伤势措辞、此刻神色、眼下之事、境况与对你的立场；主角武学与进境一节以研习账为准；后台另有「上回合正文的偏差」；PLOT_GUIDE 改为 link 只立结构性关系、一时看法由系统从 ops 记进恩怨账、人物自身可 add hp/push conditions/set intent；导演输出 scene{state 开/转/合/断, ask, by} 代替 question 与 tension、clock 立时限、cut 可写 {"until":…}，示例在 SHAPES 里轮换场况/时长/幕间省略；编剧禁写账上没有的进境、按【选项槽位】各拟一项并标「｜尺度：此刻/此后/机缘」，每项至多十八字；主角的心思不归导演写)，render/render_backstage(此地原著前提已破则明告不得照演) 把视锥(人物外貌/性情/言谈/随身/印象、近旁与同行、主角出身所求/境况/未了之事/梗概、途中(去向与余程)、按方向措辞并注明关口之类与来路的出路)与后台(焦点/受制/此地上演的原著及其原著结局/近事(其人马不得先行登场)/较量预裁/隐情/此地关口/近处暗路/研习进度/未兑现伏笔/久悬之事/节奏)压成文本，PLOT_GUIDE 教 LLM 把后果挂在每一拍上(一拍一事务、气血须有伤疗之据、身体归规则(较量与研习预裁照演、内伤分级)、10 指令、随行与拘押的关系边、带了结谓词的未了之事、spawn 场景实体且暗藏的原著器物用原名、主角只做玩家所选之事)，NAMES 教它称谓(不识名者只写叫法、听来的名字才可叫、set epithet 立名号)，THREATS 要求威胁有来源，一时的看法由系统从 ops 记进恩怨账折叠成立场(情绪写 mood、挂几回合即淡去)，原著近事不得在台词里当作已知，TIME_GUIDE 教导演光阴分两段(pace 照拍里的事如实取、研习至少一顿饭；cut 幕间省略：一幕了结、无人相逼即跳到下一处有戏的时刻，系统核对)，后台另有「阻尼」一节，编剧的伏笔多数回合写无且身体不作伏笔，_example 用本场真实 id 给一个只示格式的输出(结局/时长/幕间省略/张力随时辰在 SHAPES 里轮换，不给小模型可抄的默认值)；另有 director(不拟选项、标出本幕之问、节拍不得出现后台术语)/repair(原样拿回上一稿与账本对不上之处，只改有问题的拍)/writer(看不见后台，只凭已成立之事、未成立之事与连带成文，再写 梗概/选项(文字｜对象)/伏笔/传言)/recap/simulator/chronicler 六组 (system,user)；v5：场外推演与史官改用 OFFSTAGE 纲领(没有拍、没有主角、不立场景实体；说法只许写指令里有的变化，否则只记系统核实过的后果)，史官另看【相关者此后的原著】及其前提(_premise 译成人话)，后台的此地原著注明在近旁哪一间、或要把身边哪几人带往别处(交导演演出这一别)；TIME_GUIDE 用同一张时长表(半个时辰/一个时辰/两个时辰)；导演系统提示不再说后台只是参考，场记是「至少要处理什么」，账上真有结果才写合
agents.py: Agent 的 组装→调用→整形→兜底(v4：导演的 scene 场况、clock 时限(至多两条)、cut 的长度/入夜天明正午/{"until"} 宽松读取，场况译成本幕之问的事归引擎；编剧选项的「尺度」写在对象前后都认、先摘下再读对象；代价写在字段或括号里都认——括号写在文字末尾或对象之后皆可，说耗时路程的才是代价、其余是对象(v5)；至多八字，写不下就不写、不截半句，不写代价就不为它让出字数)——direct(逐拍{who,to,text,mood,ops}+本幕之问 question+场景实体 spawn+时长措辞 pace+幕间省略 cut(「无」与不识的措辞当没有)+原著去留 canon.unfolds+张力 tension；一句话的旧拍与顶层 effects 也收)、repair(返工一次，离线或失败返回 None 交系统作废)、write(正文+分隔线之后的梗概/选项(文字｜对象)/伏笔(期限)/可传之事，宽松读取、没写即 None 或空；给 on_text 即边写边送、分隔线后不送读者，半截分隔线先扣下，半途失声则已写出者即正文，被拦腰截断只得只言片语则以已成立之事续成，一字未得才兜底)、recap(把挤出的近事折叠进梗概，超长留新近一端)、simulate(LOD1 场外剧情)、chronicle(LOD2 改写原著，v5 附相关者此后的原著)；整形只保形状不审内容(单个字串当清单、单条指令当一批、"false"当否，绝不逐字拆散)，llm=None 或失败即走朴素 fallback(v5 唯导演遇严格模型(llm.strict)失败即抛出、整回合作废；离线说书人按全名或方向措辞认去处；兜底选项不在此处，统一归 world/menu 看局面生成)
